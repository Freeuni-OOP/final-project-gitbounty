# GitBounty
GitBounty is a Github alternative where contributing is financially incentivised.

# Running the project
```bash
docker compose up --build
```
visit https://gitbounty.foo/ to see the project.
visit http://api.gitbounty.foo/swagger-ui/index.html to see the API docs.

# Registering an account in Keycloak
http://auth.gitbounty.foo/realms/gitbounty/account/
