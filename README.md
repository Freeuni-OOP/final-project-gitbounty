# GitBounty
GitBounty is a Github alternative where contributing is financially incentivised.

# Running the project
```bash
docker compose up --build
```
visit http://localhost:8081/ to see the project.
visit http://localhost:8081/swagger-ui/index.html to see the API docs.

# Registering an account in Keycloak
http://localhost:8080/realms/gitbounty/account/
